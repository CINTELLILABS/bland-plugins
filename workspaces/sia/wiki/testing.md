# Behavioral testing

Static checks establish structure and edit scope, not conversational behavior. A behavioral comparison requires an authorized runner that executes the exact baseline and independent candidate with the same call-time settings, controlled external effects and fixed cases. No such unsaved-candidate runner is supplied by this workspace.

Record the baseline reproduction, candidate behavior, successful control and policy/error boundaries individually as passed, failed or not run, with actual execution evidence. An unsupported or unavailable runner leaves the recommendation `needs_execution`; it does not stop other supported diagnoses. Verify handoff and live calls are outside this workspace.
